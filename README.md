
# NP-Hard Problem with LLM Benchmarking

An advanced benchmarking framework to evaluate
Large Language Models on classical NP-hard problems.

## Objectives

- Compare multiple Large Language Models.
- Generate reproducible NP-hard problem instances.
- Validate model-generated solutions.
- Measure accuracy, optimality gap, latency and cost.
- Visualize benchmark results.

## Problems

1. Travelling Salesman Problem (TSP)
2. 0/1 Knapsack
3. Graph Colouring
4. 3-SAT
5. Subset Sum

## Technology Stack

- Python
- FastAPI (planned)
- Streamlit
- SQLite

- NumPy
